## Brief

The user asked for a follow-up to the 13-styles posts, this time about vector drawings, as a reference page they can return to when they need a figure for work, not a discovery essay. Scope: only the agent harnesses used in the lab (Claude Code subagents and Codex CLI). No gateway or image-model API calls in the post's work. An earlier gateway pilot (Nov 6) is not part of this post.

## How the lab ran (November 6, 2026)

- Shared brief: `lab-brief.md` (subject sentence, output rules, method: write prompt → generate from it → render → critique → revise the prompt, up to 3 rounds).
- Seven agents, two styles each: four Claude Code subagents (Claude Code 2.1.319, inheriting Opus 5.5) and three Codex CLI runs (codex-cli 0.166.0, `gpt-6.1-sol`, high reasoning, `workspace-write` sandbox).
- Codex's sandbox could not launch headless Chrome (Abort trap 6). One run used resvg as a fallback (`notes/render-notes.md`); the orchestrating Claude Code session rendered the other Codex rounds in Chrome and passed critiques back.
- Later Claude rounds were partly made by editing the previous file or with generator scripts (stated in each notes file). Codex regenerated each round from its revised prompt.
- 14 styles attempted; 13 published. Truchet was left out (street never read); see `notes/truchet-notes.md`.

## Evidence ledger

- Mechanism claims in the post: from the notes, spot-checked by the technical judge against the final SVG files (risograph, stained glass, isotype, Bauhaus, halftone, ink and wash, paper diorama, micrography, plotter, topographic, cyanotype, nocturne).
- File sizes: computed from the published SVGs.
- Browser checks: every final rendered in Chrome and in WebKit (Playwright WebKit build 2203). Halftone degrades in WebKit (light dots drop out, outlines dash, red screen bands); cause not isolated. Halftone collapses to solid tone at about 110 px wide. Firefox not checked. The draft page was checked at 390 px in WebKit: no horizontal overflow, all images load, prompt blocks wrap.
- Not done: no prompt has been blind-tested in a fresh session; subject swaps are untested.
